# CondEC
Conditional Equivalence Checking

### How to start

    git clone https://github.com/arminbiere/aiger.git
    cd aiger
    ./configure.sh && make
    cd ..

    git clone https://github.com/jix/kissat_extras.git
    cd kissat_extras
    ./configure && make
    cd ..

### Build

    ./build.sh

### Run

    ./condec_test <AIGER FILE>
