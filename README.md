# CondEC
Conditional Equivalence Checking

### How to start

    git clone https://github.com/arminbiere/aiger
    cd aiger
    ./setup.sh
    ./configure.sh && make
    cd ..

    git clone https://github.com/arminbiere/cadical.git
    cd cadical
    ./configure.sh && make
    cd ..

### run

    ./build.sh
